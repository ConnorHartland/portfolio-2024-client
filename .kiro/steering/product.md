# Product Overview

This is a personal portfolio website showcasing professional experience, projects, and technical skills. The site features:

- Landing page with personal introduction and skills showcase
- Experience timeline displaying work history
- Projects section highlighting completed work
- Blog content support via MDX/Markdown
- Responsive design optimized for desktop and mobile

The portfolio is designed for a DevOps Engineer/Software Developer with 4+ years of experience, emphasizing cloud infrastructure, automation, and full-stack development capabilities.
